About This Content

This bundle wraps the official Apache Kafka Java client and its runtime dependencies, unmodified, as an OSGi bundle.

The target platform provides org.slf4j.api 1.6.4, which lacks the org.slf4j.event package that Kafka 3.9 uses. The two classes of that package are embedded privately (slf4j-event-1.7.36.jar, extracted unchanged from slf4j-api-1.7.36.jar); all other slf4j packages are imported from the platform so Kafka log output goes to the Gumtree logging configuration.
